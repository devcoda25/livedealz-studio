# **App Name**: Live Studio Pro

## Core Features:

- Real-time Chat: Send and receive chat messages instantly using Socket.IO.
- Live Mode Sync: Synchronize the live/lobby state across all connected clients.
- Viewer and Sales Stats: Display real-time viewer and sales statistics, updating dynamically.
- Flash Deal Countdown: Implement a flash deal countdown timer that syncs across all clients.
- Moment Marker Sync: Allow creators to mark moments and sync them across clients for replay.
- Camera Preview: Display a local camera preview with mic and camera toggle and screen share feature without changing UI layout. This feature requires user's permission to access the camera and microphone.
- AI Prompt Suggestions: Provides AI-generated prompts to the streamer during live sessions, acting as a helpful tool to enhance viewer engagement and content relevance. The tool offers suggestions to respond to viewer chat or encourage deeper engagement.

## Style Guidelines:

- Primary color: Vivid orange (#F77F00) to maintain the established brand identity and create a sense of energy.
- Background color: Dark slate (#1E293B) to provide contrast and enhance the visibility of UI elements.
- Accent color: Emerald green (#03CD8C) to highlight key actions and provide visual cues for success and important updates.
- Font: 'Inter', a grotesque-style sans-serif, will be used for both headlines and body text, ensuring a clean, modern, and neutral appearance throughout the application.
